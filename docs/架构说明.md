# ClipStack 架构说明

## 依赖方向

`ClipStack.App → ClipStack.Core → Microsoft.Data.Sqlite / Windows DPAPI`。

Core 不依赖 WPF，维护数据规则及存储；App 负责交互与 Windows 集成。沿用手动构造与回调连接服务，没有新增依赖或引入容器。

## 模块职责

主界面密度保存在 `AppSettings.MainWindowDensity`，沿用现有 JSON 设置保存与回滚流程；缺失或非法枚举值回退到标准。`Controls/PanelLayout` 集中维护三档尺寸，通过窗口局部动态资源更新现有及后续虚拟化生成的卡片。应用启动读取设置，保存成功后更新布局，不重建列表或更改窗口位置。

`AppSettings.ResetListOnActivate` 默认开启，`WindowPosition` 默认为记住位置；旧配置缺项时保留默认值，非法位置枚举回退记住位置。`MainWindow.ApplySettings` 统一应用界面偏好；激活时重置列表，`HistoryController` 在成功应用最新查询结果后完成本次呼出的首条选择，避免慢查询恢复旧选中项。备注编辑和所属弹窗期间暂停激活重置。定位模式由 `WindowPlacementController` 选择目标显示器、读取鼠标物理坐标，`PanelPlacement.Resolve` 统一计算和约束边界；其他模式只更新尺寸，不覆盖记住位置的坐标。行为检查位于 `Diagnostics/PanelBehaviorChecks`。

`AppSettings.ResetFilterOnShow` 默认开启，沿用 JSON 设置存储，旧配置缺项时也开启。仅在 `MainWindow.ShowPanel` 主动呼出时将分类和选项高亮同步为「全部」，通过已有分类查询流程刷新；搜索关键词保留，与激活时列表重置独立。备注编辑和所属弹窗占用期间不切换分类，普通 `Activated` 事件也不切换，避免从设置或预览返回时改变上下文。

| 模块 | 职责 |
| --- | --- |
| `App.xaml.cs` | 启动参数分流、服务组装、事件连接、托盘动作与退出顺序 |
| `MainWindow` | 视图事件、键盘路由、编辑前后操作顺序、显示与隐藏 |
| `Controls/InlineNoteEditor` | 行内输入、字数反馈、Enter/失焦保存、Esc 取消、草稿及保存状态 |
| `ViewModels` | 可绑定的列表、预览、选择和编辑状态，无数据库访问 |
| `Services/HistoryController` | 查询、预览、收藏、备注、删除、清理、使用内容及刷新协调 |
| `Services/ClipboardCaptureWorker` | 有界采集队列、内存预算、串行持久化、退出排空 |
| `Services/ThumbnailLoader` | 可视区加载、最多两个并发解码、请求撤销、缩略图容量限制与回收 |
| `Services/SettingsService` | 快捷键、开机启动与持久设置的保存和失败回滚 |
| `Services/StartupOptions`、`Platform/BitmapCodec` | 参数解析、平台图片解码，集中复用 |
| `Platform` | Windows 剪贴板、快捷键、粘贴、单实例、托盘和窗口位置适配 |
| `Diagnostics` | 存储启动检查、窗口交互检查、系统集成检查及示例预览 |
| `Core/FavoriteNote` | 备注规范化、可见字符计数和 50 字校验，界面与存储共用 |
| `Core/DatabaseMigrator` | 数据库归属与版本检查、升级前备份、事务迁移 |
| `Core/HistoryStore` | 加密内容读写、去重、搜索、额度和清理；写连接串行，查询使用独立只读连接 |
| `Core/HistoryBackup` | 完整升级备份、SHA-256 清单、校验后恢复到新目录 |
| `Core/BoundedCache` | 按估算字节数与条数限制缓存，最近使用淘汰；同步由所属模块负责 |

没有为每个类增加对应接口。涉及外部资源的替换需求明确后，再在该边界引入接口，避免增加无用的转发层。

## 状态与异步规则

- UI 及 `HistoryController` 在 WPF Dispatcher 线程运行；耗时存储和图片解码使用后台任务，冻结后的图片可跨线程绑定。
- `HistoryStore` 使用存储锁保护写连接；查询使用独立只读连接和查询锁，在 WAL 模式下解密扫描不占用写锁。缓存由独立锁及内容修订号保护，删除或备注变更后，旧查询不能重新填入过时缓存。数据库迁移在连接对外使用之前完成。
- 列表首次读取 100 条及一条探测记录，接近底部时增加 100 条上限；保留已有记录对象与选择。搜索和分类变更立即标记旧结果不可操作并重置分页，成功应用最新查询后恢复操作。
- 数据库 v3 的 `sort_order` 单调增加，新记录、重复采集和历史使用共用排序规则；`copied_utc` 保留真实时间，单独用于显示和保留期限。重复内容会验证原内容及缩略图是否可读且一致，必要时以新采集修复并保留收藏备注。
- 查询使用取消令牌逐行取消过时搜索；查询和预览同时使用递增序号，较早请求返回时不能覆盖较新的选择或查询。
- 选择记录只更新摘要和元数据；点击「查看」时才读取全文或原图，预览关闭后清除视图模型中的原图引用。
- 普通刷新复用相同 ID 的 `ClipItem`；增删或排序未变化时保留列表对象。连续采集以约 120 毫秒窗口合并刷新，存储队列不等待界面工作；搜索采用 160 毫秒防抖。
- `HistoryStore` 的摘要/备注与长文本全文缓存各限制估算 16 MiB，列表摘要最多 512 字符；筛选先在 SQL 中完成，全文匹配仍覆盖完整原文。删除、备注修改和清理同步失效相应缓存。
- 缩略图随已实现的卡片请求/释放，滚动使用像素虚拟化。缩略图缓存限制估算 8 MiB / 128 项，预算包含编码字节与解码像素，避免缺失缩略图时缓存意外持有大原图。缓存仅在进程内，不写入明文索引。
- PNG 读取时只在 UI 线程复制剪贴板字节，完整解码和统一编码在后台进行；保留原来的内容去重行为。DIB 回退仍在 STA UI 线程读取冻结快照，随后在后台编码。
- 采集编码、历史图片回写和原图预览共用一个后台重任务槽，限制多个大图处理同时抬高内存。缩略图仍使用自己的有界加载流程。
- 行内控件只提交备注，不访问数据库；`SaveAsync` 返回错误文本时保留草稿。Enter 与失焦共用同一个保存任务，避免重复提交。
- 正在编辑的列表容器禁止虚拟化回收；查询、新复制及筛选触发的列表替换延后到全部备注保存或取消以后。缩略图加载可以继续。
- `FavoriteNote` 按 Unicode 文本元素计数，不使用 `TextBox.MaxLength` 截断 UTF-16 字符。输入超限时即时提示并拒绝保存；已有长备注读取不截断。
- 采集队列最多 16 项，同时限制内容与缩略图总计 32 MiB。队列满时释放预算并显示提示；保存成功或失败均在 finally 中归还预算。
- 清理时暂停监听并使旧采集策略失效，经保存队列屏障等待已有数据落盘后执行清理，随后恢复暂停状态。设置保存提交与维护清理分开处理，保存失败回滚系统设置，清理失败仅报告维护提示；保存期间禁止关闭设置窗口。
- 正常退出先提交备注；失败时保留编辑窗口。停止定时任务，等待设置保存，停止接收新剪贴板事件并等待已开始的采集任务，排空保存队列，等待历史操作，最后释放托盘、数据库和单实例资源。
- 自动粘贴前核对目标窗口、前台焦点、修饰键及剪贴板序号；失败时重新显示面板并提示用户复制后手动粘贴。未处理界面异常暂停采集并提供有序退出，日志仅记录应用方法名等诊断元数据。
- 系统强制终止进程无法保证尚未落盘的队列或草稿保存，发布脚本按用户要求可以停止指定发布目录里的旧程序。

## 扩展位置

| 需求 | 修改位置及检查点 |
| --- | --- |
| 新增内容类型 | `ClipKind` / `CapturedClip`、采集平台适配、存储限额、预览与回写；补充该类型的读写验证 |
| 新增历史操作 | `HistoryController` 实现业务，视图发出操作意图，保持数据库访问集中 |
| 新增设置 | `AppSettings` 定义和规范化，设置视图输入，`SettingsService` 处理外部副作用与回滚 |
| 调整备注规则 | `FavoriteNote` 统一修改；控件与存储都使用该规则 |
| 修改窗口定位 | `WindowPlacementController` 适配物理坐标与 DPI，`PanelPlacement` 维护边界算法 |
| 增加数据库版本 | 新增嵌入 SQL、在 `DatabaseMigrator` 追加版本顺序；保持升级前备份与事务执行 |
| 新增诊断入口 | `StartupOptions` 解析、`DiagnosticRunner` 分流、`Diagnostics` 实现，避免混入正常启动 |

本次新增 v3 排序字段，内容加密格式及默认数据路径保留。视图与 Windows 服务仍有明确类型关联，未来需要跨平台或无界面运行时，可进一步提取平台接口；当前面向 Windows 桌面的范围内保持这些边界更易维护。

## 验证入口

```powershell
.\scripts\Publish.ps1
.\scripts\Test-Release.ps1
```

发布脚本检查核心规则、单 EXE 读写、真实窗口位置、行内备注及性能相关资源约束，并生成界面预览。`--integration-test` 另外覆盖系统剪贴板、快捷键、单实例与目标窗口回贴；会临时使用剪贴板，结束时恢复。普通预览、窗口及性能诊断不修改系统剪贴板。
