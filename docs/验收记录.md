## 数据库与备份

- 旧 v1/v2 数据库启动时先完整备份，再在事务内升级到 v3；新增 sort_order INTEGER NOT NULL DEFAULT 0 及倒序索引。
- 数据库升级.sql 对应 v1 → v3；数据库升级-v2到v3.sql 对应 v2 → v3。程序自动执行，文件供查阅，不能重复手工执行。
- 完整备份位于数据目录 backups/history-.../，backup.json 保存文件校验清单。恢复仅接受尚不存在的新目录，需要原 Windows 用户解密；命令见《使用说明》。
- 升级前备份失败则停止迁移；旧版本的单个数据库备份不等于完整备份。备份占用额外空间，需要自行管理。
