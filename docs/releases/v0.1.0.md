# ClipStack v0.1.0

首个开源版本，采用 MIT 许可证。面向个人自用的 Windows 剪贴板历史工具。

## 下载使用

下载 `ClipStack-win-x64.zip`，解压后双击 `ClipStack.exe`；也可直接下载 EXE。无需安装 .NET 或数据库，无需管理员权限。

支持 Windows 10 22H2 / Windows 11 x64。默认快捷键为 `Ctrl + Alt + V`，`Esc` 隐藏；退出入口位于托盘菜单或主界面「更多」菜单。

## 功能

- 保存文本和图片，支持搜索、收藏、自动清理和排除进程。
- 收藏支持原位编辑简单备注，最多 50 个可见字符。
- 浅色悬浮面板，提供紧凑、标准、宽松三种密度。
- 支持记住位置、跟随鼠标、屏幕中间、屏幕右侧；可配置激活时选中首条。
- 托盘图标可配置，主窗口不显示在任务栏；支持开机后台启动。
- 内容仅保存于本机，正文、图片和备注使用 Windows 当前用户加密保护。
- 已修复清理菜单不生效，以及首次启动时默认位置轮廓闪现的问题。

## 验证与已知限制

发布脚本执行存储、窗口交互、性能行为与自包含启动检查，诊断使用独立测试数据。

当前程序未签名，下载运行时可能出现未知发布者或 SmartScreen 提示。干净机器、多显示器不同 DPI 和长时间常驻仍需进一步验证。自动回贴受到 Windows 前台窗口限制时，可使用 `Ctrl + V` 手动粘贴。

`SHA256SUMS.txt` 用于校验 EXE。ZIP 中保留项目及第三方许可证。
