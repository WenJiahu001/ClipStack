# ClipStack v0.2.1

本版减少剪贴板监听时的瞬时锁竞争，并改善 Windows 默认 PowerShell 环境的发布脚本兼容性。

- 剪贴板监听收到更新通知后增加短暂让步延迟（首次 40 ms），避免与来源程序（如 Flow Launcher 插件、OLE 刷出或连续多格式写入）在 0 ms 抢占 `OpenClipboard` 导致对方复制失败。
- 将 `ExcludedProcesses` 排除进程判断提前到 `OpenClipboard` 之前，并优先使用 `OpenProcess` + `QueryFullProcessImageName` 获取进程名；命中排除列表时不再打开或锁定剪贴板。
- 将文本 `\0` 截断及 UTF-8 字节长度校验移出 `OpenClipboard` 锁内，缩短持锁窗口并修复空文本分支判断。
- 发布、许可收集与便携性检查脚本兼容 Windows PowerShell 5.1（补充 UTF-8 BOM、`-Encoding UTF8` 及 JSON 对象遍历），并随 `.NET 10 SDK 10.0.404` 同步更新锁文件。
