# ClipStack v0.2.0

本版修复异步操作和存储一致性问题，并改善较多历史下的响应速度。

- 搜索及分类切换立即禁用旧结果操作，防止误复制、粘贴或删除。
- 设置提交与历史清理分开处理，保存失败回滚快捷键和开机启动；保存期间阻止关闭窗口。
- 清理先协调采集与保存队列；退出等待尚未完成的图片处理，避免清理后记录重现或最后一张图片被丢弃。
- 新增独立排序序号，统一新增、重复复制及使用内容的置顶规则；重复复制可修复损坏正文或缺失图片。
- 历史每批加载 100 条，查询独立读取连接；历史图片解码放入共享后台任务槽。
- 新增“呼出时默认切换到「全部」”配置，默认开启；关闭后保留上次分类，搜索关键词保留。
- 修复横向滚动条，完善异常暂停、退出提示及不包含复制内容的诊断位置。
- 数据库自动升级到 v3，升级前完整备份图片、密钥和配置，并提供校验恢复命令。

自动粘贴仍受 Windows 前台焦点和目标应用限制；失败时重新显示面板，提示复制后手动粘贴。具体检查结果及环境限制见验收记录。
