# 第三方组件

构建版本的准确版本号及依赖关系以 `packages.lock.json` 为准。

| 组件 | 用途 | 许可证 / 官方来源 |
| --- | --- | --- |
| .NET / WPF | 随程序分发的运行时与桌面框架 | MIT；https://github.com/dotnet/runtime 与 https://github.com/dotnet/wpf |
| Microsoft.Data.Sqlite | SQLite 数据访问 | MIT；https://github.com/dotnet/efcore |
| SQLitePCLRaw | SQLite 原生调用及原生库打包 | Apache-2.0；https://github.com/ericsink/SQLitePCL.raw |
| SQLite | 嵌入式数据库 | 公有领域；https://sqlite.org/copyright.html |

构建脚本会将解析得到的第三方许可证和 .NET 自包含运行时的许可文件一起收集到发布目录。EXE 内「设置 → 开源组件与许可」也内置许可文本。整包分发时应保留 THIRD-PARTY-NOTICES.txt 及 licenses 文件夹。
