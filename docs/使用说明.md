# ClipStack 使用说明

## 打开即用

将 `ClipStack.exe` 放到本机一个固定位置后双击运行。无需安装，无需预装 .NET、SQLite 或 WebView2，断网也能使用。首次启动后开始记录新的复制；不会读取 Windows 自带的历史。

应用面向 Windows 10 22H2 与 Windows 11 的 Intel/AMD 64 位电脑；ARM64、32 位和 Windows 7/8 不在首版验收范围内。

## 常用操作

| 操作 | 方式 |
| --- | --- |
| 打开历史面板 | `Ctrl + Alt + V` 或双击托盘图标 |
| 选择记录 | 鼠标点击或搜索框中按上下方向键 |
| 切换分类 | 左右方向键循环切换全部、文本、图片、收藏；搜索框有文本或编辑备注时保留光标移动 |
| 快速粘贴 | 回车、双击记录或点击「粘贴」 |
| 仅复制记录 | `Ctrl + C` 或点击「复制」 |
| 搜索记录 | 直接输入中文或英文片段 |
| 收藏、删除 | 点击每条记录右上角的星标、删除图标 |
| 收藏备注 | 点击卡片左下角「添加备注」或铅笔，原位输入，回车或移开焦点保存，Esc 取消 |
| 查看全文或大图 | 选中记录后点击底部「查看」，或在列表中按空格 |
| 隐藏面板 | `Esc`、隐藏按钮或点击其他应用 |
| 暂停记录 | 右上角「…」菜单或托盘菜单 |
| 清理历史 | 右上角「…」菜单 |
| 彻底退出 | 右上角「…」菜单「退出 ClipStack」或托盘菜单「退出」 |

主界面采用浅色单列布局；顶部搜索和分类，每条记录直接提供复制、收藏、删除。文本显示摘要，图片显示缩略图，底部「查看」可按需打开完整内容预览。

设置中的“呼出时默认切换到「全部」”默认开启：每次呼出面板时选中顶部的「全部」，关闭后保留上次选择的文本、图片或收藏分类。搜索关键词保留；与「激活窗口时，滚动至顶部并选中首条」独立。保存后下次呼出生效，重启后保留，旧配置默认开启。返回设置或内容预览、编辑备注期间不会重置分类。

「设置 → 复制后隐藏窗口」默认开启：点击复制按钮或使用 Ctrl+C 成功复制后自动隐藏面板；关闭后复制完成仍保留面板，方便连续操作。保存后立即生效，重启后保留；旧配置默认开启。

点击右上角齿轮，在「主界面紧凑程度」选择紧凑、标准或宽松，点击「保存设置」后立即生效，重启后保留。默认标准；紧凑模式减少留白，文本最多预览两行、图片高度较小；宽松模式增加留白，文本最多预览四行、图片高度较大。字体、按钮大小及窗口位置尺寸不随之改变，完整内容仍可通过「查看」打开。取消设置不会应用此次选择。

历史每批加载 100 条，向下滚动接近底部时继续加载，数量后的「+」表示还有更多。图片随滚动加载缩略图；选中时不会提前打开原图，点击「查看」后再读取。首次打开较多历史时可能短暂显示「正在加载历史」。搜索匹配完整正文，搜索更新期间暂时禁用旧结果的复制、粘贴和删除，防止误用旧选中项。

收藏备注为最多 50 字的单行短备注，在卡片左下角以小字显示。点击备注或铅笔后直接在原位置输入，不弹出编辑窗口；Enter 保存、移开焦点自动保存、Esc 放弃本次修改。字数按可见字符计算，表情和组合字符不会被拆开；粘贴的换行和制表符会转为空格。超过 50 字或保存失败时会在输入框下提示并保留草稿，请精简后保存或按 Esc 取消。

较长备注以省略号收起，悬停可查看全文；内容预览窗口也会显示完整备注。搜索可匹配备注；复制、粘贴只使用原内容。留空保存可清除备注；取消收藏时隐藏备注，再次收藏会恢复显示。旧版本已有的长备注不会被自动截断，修改后保存须符合 50 字限制。编辑时列表暂缓刷新，保存或取消后恢复，防止新复制内容打断输入。

设置中的「激活窗口时，滚动至顶部并选中首条」默认开启。每次呼出或重新激活主面板时，回到当前搜索、分类下的首条记录；异步加载完成后也会选中最新首条。关闭后不主动重置滚动位置和选择。编辑备注及从设置、预览窗口返回时不会打断操作。

主窗口始终不显示在任务栏。「显示托盘图标」默认开启，保存后立即生效，重启后保留。关闭后可通过全局快捷键或重新运行 EXE 唤回窗口；在右上角「…」菜单选择「退出 ClipStack」可彻底退出。关闭托盘图标时不显示托盘气泡通知，操作提示仍会显示在主面板状态栏。

设置中的「窗口位置」决定下次呼出的位置，保存后生效并在重启后保留：

| 模式 | 行为 |
| --- | --- |
| 记住位置（默认） | 拖动标题栏后记住位置；首次没有已记住位置时，在当前工作窗口所在屏幕右侧显示 |
| 跟随鼠标 | 在鼠标所在屏幕的指针附近显示；靠近右侧或底部时改在另一侧，并避开任务栏 |
| 屏幕中间 | 在当前工作窗口所在屏幕的工作区中间显示 |
| 屏幕右侧 | 在当前工作窗口所在屏幕的右侧显示，垂直居中 |

其他模式下拖动不会覆盖「记住位置」的坐标，切回该模式仍可恢复；调整窗口大小仍会记住。显示器断开或工作区缩小时，自动调整到当前可见区域。浅色面板使用系统窗口阴影和清晰边框，与工作背景区分。

默认快捷键已被占用时，应用尝试 `Ctrl + Alt + Shift + V`。面板左下角显示实际快捷键；两者均不可用时会直接打开主面板，进入设置修改。隐藏托盘后也可重新运行 EXE 唤回已有窗口。

粘贴会尝试返回呼出面板前的窗口。目标窗口失去焦点、已经关闭、权限更高或系统剪贴板又被更新时，会停止自动粘贴并重新显示面板提示。此时点击「复制」，再返回目标应用按 `Ctrl + V`。部分目标应用不接受图片或忽略模拟按键，此时可使用「复制」后自行粘贴。

## 保存范围

- 文本按纯文本保存，原空格、缩进、换行和表情保留。
- 支持截图、浏览器的「复制图片」等位图内容，不保存资源管理器复制的图片文件路径。
- 不保留 Word/网页排版，不执行复制的脚本，不提供图片 OCR。
- 同一次剪贴板有图片和文本时，优先保存图片。
- 支持 PNG、DIB、DIBV5 和位图回退；来源私有格式不保证能还原。
- 超过 1 MiB 文本、20 MiB 编码后图片或 2,500 万像素的图片会跳过，状态栏显示原因。
- 极快连续复制时，若来源在读取前已覆盖剪贴板，旧内容无法恢复。应用不承诺捕获系统上每一个瞬时变化。

默认保留 1,000 条、30 天普通历史、500 MB 图片。收藏免于普通过期删除，但仍占条数与图片预算；收藏占满时停止新增并提示。点击复制、双击、回车或快捷键成功复制内容后，该条记录会移动到当前列表顶部；重复复制相同文本或图片只保留一条并置顶，收藏和备注保留。时间标签及普通历史保留期限按最近复制或使用时间计算。

## 隐私与数据

数据目录：`%LOCALAPPDATA%\ClipStack`。

文本正文、图片、缩略图及收藏备注由 Windows DPAPI 以当前用户身份加密；数据库中的类型、时间、大小与收藏状态是明文元数据。内容指纹使用本机加密保存的密钥计算 HMAC。应用没有网络请求、账号或遥测；日志不记录正文、备注及图片。

窗口位置保存在数据目录的 `panel-position.json`，与其他偏好独立保存。v0.2.0 使用数据库 v3，以独立序号排序，真实复制时间用于显示和过期判断。旧版数据库首次打开时会先完整备份到 `backups\history-...\`，再自动迁移；备份包含数据库、仍被引用的图片和缩略图、指纹密钥及已有配置，`backup.json` 为完整性校验清单。备份不计入普通历史的图片额度，需要自行管理保留空间。

发布目录内 `数据库升级.sql` 适用于 v1 → v3，`数据库升级-v2到v3.sql` 适用于 v2 → v3，均供查阅，无需手动执行且不可重复执行。旧版程序无法读取升级后的数据库，回退前应恢复完整备份。

可先退出程序，运行以下命令恢复到一个**尚不存在的新目录**，再打开恢复后的历史；仍须使用原 Windows 用户。该命令不会覆盖当前数据：

```powershell
.\ClipStack.exe --restore-backup "C:\备份\history-完整备份目录" --data-dir "C:\恢复\ClipStack"
.\ClipStack.exe --data-dir "C:\恢复\ClipStack"
```

原版本只有单个数据库文件的备份缺少图片和密钥，不能按此方式完整恢复。

加密保护不阻止同一登录用户权限下的恶意程序；也不意味着在屏幕上展示的历史不会被看到。复制敏感信息前可暂停记录。来源应用提供的禁止历史记录标记会被尊重；应用排除规则按剪贴板所有者进程名匹配，未知来源无法保证识别。

暂停状态只持续到退出应用。重新启动默认恢复记录。清理时暂时停止采集，处理完清理前已排队的数据后再删除，并取消清理前尚未完成的图片采集，避免旧记录重新出现。清理历史不会清空系统当前剪贴板，也不会清理 Windows 自带历史。磁盘删除不承诺取证级擦除。

移动 EXE 不影响数据。启用开机启动后移动程序，请重新打开设置保存，以更新路径。数据不是与 EXE 同目录的跨机便携存档；复制到另一用户或重装系统后可能无法解密。

备份时先退出程序，再备份整个数据目录。升级前退出旧版本，替换 EXE 后运行；遇到未来版本数据库时，旧版会拒绝写入。删除程序本体不会删除历史，设置页显示数据位置，可退出后手动删除该目录。

## 运行失败

- 数据目录不可写或磁盘不足时，会显示错误并保留原数据；修复后重试。
- 图像文件丢失或解密失败时，不会自动删除原记录；可恢复备份或手动删除问题记录。
- 诊断日志为数据目录中的 `diagnostics.log`，仅包含时间、操作、错误类型、代码及应用方法名，不包含正文、备注、图片、文件路径或调用参数。
- 设置保存期间会暂时禁用设置窗口关闭；设置已保存但清理失败时，会分别提示。遇到未预期界面异常时会暂停记录，并提供保存已有采集后退出的选项；未保存备注仍会受到保护。
- 此 EXE 启动时会向临时缓存释放随包原生库；临时目录必须可写，企业应用控制策略仍可能阻止运行。
- 未签名内测版可能有系统提示。正式签名版也不能保证所有设备均无 SmartScreen 提示。请从可信来源核验发布者和 SHA-256，无需关闭安全防护。
